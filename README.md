# 🎮 Honkai: Star Rail Discord Bot

بوت ديسكورد متقدم وشامل لـ Honkai: Star Rail يوفر معلومات شاملة عن الشخصيات والفرق والآثار ومخاريط الضوء.

## ✨ المميزات الرئيسية

### 🔍 أوامر البحث والمعلومات
- **`!character <name>`** - عرض معلومات تفصيلية عن الشخصية
- **`!search <name>`** - البحث عن شخصية
- **`!list [path/element]`** - عرض قائمة الشخصيات مع إمكانية التصفية
- **`!stats <character>`** - عرض إحصائيات الشخصية بالتفصيل

### ⚔️ أوامر الاستراتيجية
- **`!team <character>`** - أفضل الفرق الموصى بها للشخصية
- **`!compare <char1> <char2>`** - مقارنة شخصيتين
- **`!tier`** - عرض Tier List لأفضل الشخصيات

### 🎁 أوامر المعدات
- **`!relics <character>`** - أفضل الآثار والإحصائيات المطلوبة
- **`!lightcone <character>`** - أفضل مخاريط الضوء

### 📚 أوامر المعلومات
- **`!path [path]`** - معلومات عن المسارات (Paths)
- **`!element [element]`** - معلومات عن العناصر (Elements)
- **`!tip`** - نصيحة عشوائية مفيدة

### 🎛️ أوامر أخرى
- **`!help`** - عرض قائمة الأوامر الكاملة
- **`!ping`** - اختبر اتصال البوت

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 16.0 أو أحدث
- حساب Discord Developer
- Bot Token من Discord

### خطوات التثبيت

1. **استنساخ المشروع أو تحميله**
```bash
cd hsr-discord-bot
```

2. **تثبيت المكتبات**
```bash
npm install
```

3. **إنشاء ملف `.env`**
```bash
DISCORD_TOKEN=YOUR_BOT_TOKEN_HERE
CLIENT_ID=YOUR_CLIENT_ID_HERE
GUILD_ID=YOUR_GUILD_ID_HERE
```

4. **تشغيل البوت**
```bash
npm start
```

## 📖 كيفية الحصول على Bot Token

1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. انقر على "New Application"
3. اذهب إلى "Bot" وانقر على "Add Bot"
4. انسخ Token تحت "TOKEN"
5. الصقه في ملف `.env`

## 🔧 الميزات المتقدمة

### نظام الأزرار التفاعلية
عند عرض معلومات الشخصية، يمكنك الضغط على الأزرار التالية:
- 🎯 الفرق - لعرض أفضل الفرق
- 🎁 الآثار - لعرض أفضل الآثار
- 💫 مخاريط الضوء - لعرض أفضل مخاريط الضوء

### نظام البحث الذكي
- البحث باللغة العربية والإنجليزية
- دعم البحث الجزئي عن أسماء الشخصيات
- اقتراحات سريعة عند عدم العثور على نتيجة

### نظام التصفية
- تصفية الشخصيات حسب المسار (Path)
- تصفية الشخصيات حسب العنصر (Element)
- تصفية الشخصيات حسب الندرة (Rarity)

## 📊 البيانات المتضمنة

### الشخصيات
- 7+ شخصيات مع معلومات شاملة
- إحصائيات كاملة (HP, ATK, DEF, SPD, CRIT)
- نقاط القوة والضعف
- أفضل الفرق المقترحة

### المسارات (Paths)
- 9 مسارات مختلفة مع وصف لكل منها
- الشخصيات المنتمية لكل مسار

### العناصر (Elements)
- 7 عناصر مختلفة
- الشخصيات المنتمية لكل عنصر

### الآثار (Relics)
- 4+ أنواع آثار مختلفة
- الإحصائيات الرئيسية والثانوية

### مخاريط الضوء (Light Cones)
- 4+ مخاريط ضوء مختلفة
- الوصف والفوائد لكل واحدة

## 🎨 نظام الألوان

البوت يستخدم نظام ألوان متقدم:
- 🔵 **أزرق** - للمعلومات الأساسية
- 🟣 **بنفسجي** - للمعلومات الثانوية
- 🟢 **أخضر** - للنجاح والتوصيات
- 🔴 **أحمر** - للتحذيرات
- 🟡 **أصفر** - للتنبيهات المهمة
